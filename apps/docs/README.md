# CueLingo Docs (`@cuelingo/docs`)

Toàn bộ tài liệu của CueLingo, dựng bằng Docusaurus 3. Nguồn ở `docs/`.

```bash
pnpm --filter @cuelingo/docs dev     # http://localhost:3100
pnpm docs:build                      # build + kiểm link hỏng (chạy trong CI)
```

Viết trang mới: xem [Viết tài liệu](docs/05-engineering/conventions/writing-docs.md).
